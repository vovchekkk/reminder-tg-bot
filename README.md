# 🤖 Universal Telegram Reminder Bot

Универсальный Telegram-бот для напоминаний с контролем выполнения (кнопка галочки), написанный в **одному файле** (`bot.py`) на Python (`aiogram 3`).

---

## 🌟 Возможности

1. **⚡ Быстрый шаблон под ваш запрос:**
   - Кнопка в меню: `⚡ Физра (Пн, Пт каждый час)`.
   - В 1 клик создает напоминание: каждый понедельник и пятницу, с 09:00, с повторением каждый 1 час, пока не нажмете галочку.
2. **✅ Кнопка галочки под напоминанием:**
   - Под каждым сообщением напоминания выводится инлайн-кнопка **`[ ✅ Сделано! ]`**.
   - При нажатии бот хвалит: *"🎉 Ура, вы молодец! Задача выполнена!"* и **останавливает напоминания**:
     - Для повторяющихся: до следующего назначенного по расписанию дня.
     - Для одноразовых: навсегда отключает напоминание.
   - **Если не нажали:** бот настойчиво повторяет напоминание через заданный интервал (по умолчанию каждый час).
3. **🛠 Полная универсальность (Конструктор):**
   - **Свой текст:** любой текст задачи (например: *«Полить цветы»*, *«Выпить витамины»*, *«Сдать отчет»*).
   - **Свои дни недели:** интерактивный выбор кнопками (`[✅ Пн] [Вт] [Ср] [Чт] [✅ Пт] [Сб] [Вс]`).
   - **Своя частота напоминаний:** 15 мин, 30 мин, 1 час, 2 часа или свой произвольный интервал в минутах.
   - **Одноразовые напоминания:** на конкретное время (`18:30`, `30.09 14:00`) или относительное (`через 10 мин`, `через 1 час`, `+45m`, `+2h`).
4. **📋 Удобное управление:**
   - Список всех напоминаний в меню **«📋 Мои напоминания»**.
   - Кнопка **«🔔 Проверить сейчас»** для мгновенного теста отправки.
   - Пауза / возобновление (`⏸️ / ▶️`).
   - Удаление (`❌`).
5. **💾 Надежность и сохранение данных:**
   - Встроенная база данных **SQLite** (`reminders.db`) — все напоминания и отметки о выполнении сохраняются даже при перезапуске бота или сервера.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```
*(Или вручную: `pip install aiogram python-dotenv`)*

### 2. Получение токена бота
1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям.
3. Скопируйте полученный токен (вида `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

### 3. Настройка конфигурации
Создайте файл `.env` рядом с `bot.py` (или скопируйте `.env.example`):
```env
BOT_TOKEN=ваш_токен_от_BotFather
BOT_TIMEZONE=Europe/Moscow
```

### 4. Запуск бота
```bash
python bot.py
```

---

## 📱 Как пользоваться

1. Откройте бота в Telegram и отправьте `/start`.
2. Чтобы сразу создать напоминание по физре — нажмите кнопку **`⚡ Физра (Пн, Пт каждый час)`**.
3. Чтобы проверить, как приходит напоминание с кнопкой — перейдите в **`📋 Мои напоминания`** -> выберите напоминание -> нажмите **`🔔 Проверить сейчас`**.
4. Нажмите **`✅ Сделано!`** — бот напишет поздравление и деактивирует повторы!
5. Чтобы создать произвольное напоминание — нажмите **`➕ Создать напоминание`** и пройдите короткий пошаговый мастер.
